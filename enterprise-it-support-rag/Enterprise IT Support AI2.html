Evaluation Methodology and Limitations

The evaluation used a custom dataset containing 10 IT support questions.

The same Qwen model was used for answer generation and judging, so the evaluation is not independent.

Context precision and context recall are LLM-judge estimates, not official RAGAS results. These scores should be interpreted as results from this test set, not a guarantee of general performance.
