Enterprise IT Support RAG Assistant

Interactive end-to-end architecture walkthrough · Two pipelines: prepare the knowledge base, then retrieve and generate answers for employees.

Cyan = current step · Green = completed step · Dashed moving arrows = active data flow. Select any step card to jump directly to it.

Technology stack — current

  • Python 3.12
  • Streamlit frontend
  • FastAPI backend
  • all-MiniLM-L6-v2 embeddings
  • ChromaDB vector database
  • BM25 + Reciprocal Rank Fusion
  • Ollama + Qwen 2.5:3b
  • RAGAS evaluation setup

Current configuration

  • Chunk size: 700
  • Chunk overlap: 120
  • Top-K: 5
  • FastAPI: port 8001
  • Streamlit: port 8501
  • 10 sample IT support TXT documents

Evaluation baseline

  • Hit@5: 1.000
  • MRR@5: 0.900
  • Five-question retrieval test
  • RAGAS: Faithfulness, Answer Relevancy, Context Precision, Context Recall — evaluation in progress

Planned enhancements

  • Cross-encoder reranking
  • Query rewriting and HyDE
  • Stronger citations and evidence fallback
  • Document management and feedback
  • Authentication and secure uploads
  • Automated tests, load tests and deployment hardening
